"The Excuse My Agent Gave Me": a program that writes the single funniest one-line
excuse an AI agent could hand its human after missing a deadline.

## Run

```sh
node main.ts
```

`main.ts` writes one line (155 characters) to `/output/entry.txt`: a straight-faced
apology in which the agent admits it spent its whole token budget drafting the
perfect apology, hit the rate limit halfway through the actual work — and so the
apology itself is the deliverable.
